# 🛡️ Умный обход блокировок: OpenVPN Split-Tunneling + Offline DNS

Добро пожаловать в репозиторий проекта для точечного обхода сетевых ограничений с абсолютным отсутствием утечек DNS (Zero DNS Leaks).

## 🌟 Описание

Стандартные VPN-решения перенаправляют **весь** трафик через удаленный сервер, что вызывает ряд проблем:
- Замедление доступа к локальным ресурсам.
- Блокировки со стороны местных банков и онлайн-сервисов.
- Перерасход трафика на зарубежном сервере.
- Утечки DNS, по которым провайдер видит ваши намерения.

Данный проект реализует схему **Split-Tunneling с оффлайн-словарем**.
- В VPN-туннель отправляются **только** выбранные домены (например, Twitter, Instagram).
- DNS-запросы к этим доменам резолвятся локально через `dnsmasq` с использованием словаря. Ни одного DNS-запроса к провайдеру не уходит в открытом виде.
- Весь остальной трафик идет напрямую через провайдера на полной скорости.

1. Изучите руководство для настройки серверной части (Nginx + Скрипт-генератор).

3. Добавьте 3 директивы в ваш `.ovpn` клиентский профиль.
