# 🛡️ Умный обход блокировок: OpenVPN Split-Tunneling + Smart DNS Learner

Добро пожаловать в репозиторий проекта для точечного обхода сетевых ограничений с полным отсутствием утечек DNS (Zero DNS Leaks).

## 🌟 Описание

Стандартные VPN-решения перенаправляют **весь** трафик через удаленный сервер, что вызывает ряд проблем (потеря скорости, блокировка банков, перерасход трафика).

Данный проект реализует продвинутую схему **Гибридного Split-Tunneling**:
1. **Динамический роутинг (ipset):** При обращении к заблокированному сайту DNS-запрос улетает на VPN-сервер по зашифрованному туннелю. Клиент мгновенно записывает ответ в память (ipset) и направляет трафик в VPN.
2. **Самообучающийся кэш (Smart Learner):** Фоновый демон анализирует ваш трафик. Если сайт выдал один и тот же IP-адрес **3 раза с интервалом не менее 20 минут**, адрес признается "стабильным" и навсегда записывается в локальный текстовый оффлайн-словарь. В будущем трафик для этого сайта будет работать аппаратно из кэша даже без обращения к DNS VPN-сервера!

## ✨ Главные фичи
- 🔒 **Zero DNS Leak**: Провайдер не видит ваших DNS-запросов.
- ⚡ **Автономность**: Система сама учится и формирует локальный кэш стабильных адресов, отсеивая временные узлы CDN.
- 🚀 **Изоляция**: Банки, Госуслуги и YouTube работают через родного провайдера на полной скорости.
